Birthday website

Open index.html. No video is needed; the video and portrait pages have been removed.

Page order: animated heart tree -> gift -> three candle wishes -> balloons -> photos -> flip wishes -> Kerala -> envelope -> letter -> birthday ending.

The tree draws itself, then hearts appear one by one. Cake layers fall into place. Read each wish and tap to drop its candle; it lights after landing. One tap blows out all three candles.

Optional files in this folder:

photo1.jpg, photo2.jpg, photo3.jpg: replace the photo placeholders
